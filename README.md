## 付款失败时先排查什么

### 1. 提交了普通 X 页面链接

这是最常见的问题。BeWild 需要的是 X 跳转后的 Stripe 订阅链接，不是 X Premium 介绍页链接。

处理方式是重新登录 X，重新进入月付订阅流程，再复制浏览器地址栏中的完整链接。

### 2. 误用了年付链接

BeWild 的帮助中心明确说明，X 产品目前只支持月付，不支持年付。如果提交的是年付订阅链接，平台可能识别出错误的周期或金额。此时不要继续支付，应该返回 X Premium 页面重新生成月付链接。

### 3. 手机端操作不完整

X 的订阅跳转和 Stripe 页面在手机端更容易出现兼容问题，例如链接复制不完整、页面打不开、返回平台后内容丢失。官方建议改用电脑端重新操作。

### 4. 代理或 VPN 导致 Stripe 页面异常

帮助中心建议遇到付款失败时，先关闭代理或 VPN 刷新页面；如果仍然无法完成，可以尝试更换网络环境，再重新生成订阅链接。不要在同一个失效链接上反复提交，因为链接本身可能已经过期。

### 5. 订单已经付款，但 X 里还没显示会员

先等待平台订单状态更新，然后退出并重新登录 X，查看 Premium 订阅页面。

确认路径可以从两个地方入手：

- BeWild 的“我的订单”中是否已经显示已开通；
- X 的订阅设置中是否出现套餐类型和下次扣费日期。

如果 BeWild 显示已完成，但 X 仍然没有会员状态，准备好订单信息、X 订阅页面截图和账号邮箱，再联系客服核查。不要在没有确认原订单状态前重新下单。
